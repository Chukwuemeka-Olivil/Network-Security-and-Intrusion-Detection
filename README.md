# Network Security and Intrusion Detection

A collection of cybersecurity labs focused on secure network communication, network access control, intrusion detection, and network traffic analysis completed in a Kali Linux virtual environment.

## Security Areas

- SSL/TLS and HTTPS security
- SSH secure remote access
- SSH hardening
- IPsec VPN configuration
- Network access control
- 802.1X authentication
- RADIUS authentication
- Intrusion Detection Systems (IDS)
- Network traffic monitoring
- Network traffic analysis
- Packet capture and analysis
- Security event detection
- Security configuration troubleshooting

## Environment

- Kali Linux
- VMware Workstation
- Virtualized laboratory environment
- OWASP Broken Web Applications VM
- Controlled and authorized testing environment

## Ethical and Authorized Testing

All security testing documented in this repository was performed for educational purposes within a controlled virtual laboratory environment.

Testing involving network traffic generation and security monitoring was conducted only against laboratory systems designated for testing, including the OWASP Broken Web Applications virtual machine.

No unauthorized systems or third-party services were targeted.
